PDReader

把 PDReaderSetup.exe 拷到另一台 Windows 电脑上，双击即可安装。
安装后可从开始菜单或桌面打开，不需要再安装 Python。

使用前请确认：
1. 电脑是 64 位 Windows 10 或 Windows 11。
2. 打开 PPT/PPTX 需要本机已安装 Microsoft PowerPoint 或 WPS；打开 PDF 课件不需要 Office。
3. Windows 11 一般已自带 WebView2；若程序打不开，请安装 Microsoft Edge WebView2 运行时。
4. 打开课件后即可生成讲稿和提问。平台积分可在软件内加微信兑换充值。

默认安装到当前用户目录，也可以在安装窗口里修改路径或点「浏览」自选文件夹，不需要管理员权限。
复制文件时窗口会显示进度，可能需要一两分钟，请不要强制结束。
如果是从软件内更新，安装程序会先关闭正在运行的 PDReader，请继续选原来的安装目录。
设置、缓存和积分账号会保存在当前 Windows 用户目录，卸载程序不会删除这些个人数据。
