# 使用 PDReader

## 配置自有 API

在「设置」里填写 Base URL、API Key 和模型名称，保存后点击「测试连接」。Base URL 是接口根地址，例如服务商提供的 `https://api.example.com/v1`，不要填完整的 `/chat/completions` 或 `/responses` 地址。多数服务使用 Bearer 授权；仅在服务商要求时切换为「仅密钥」。

客户端支持兼容的 Chat Completions / Responses 接口并包含回退处理，但不同服务商的实现可能存在差异。使用页面图片和截图需要支持图像输入的模型。联网搜索依赖服务支持 Responses 的搜索工具，不是所有兼容接口都能用。

在右下角选择「自有 API」。如果已有平台积分，客户端可能自动选中平台通道，请在发送前确认。

## 阅读和复习

1. 点击「打开课件」或把文件拖到中央阅读区。PDF 无需安装 Office；PPT/PPTX 依赖本机 PowerPoint 或 WPS COM 组件。
2. 点击左侧缩略图切页；阅读区支持滚轮和方向键翻页。拖动栏间分隔条可以调整空间。
3. 生成本页讲稿，或批量生成尚未缓存讲稿的页面。关闭后再次打开同一版本课件可复用缓存。
4. 粘贴截图或点击「添加截图」，围绕当前页提问。聊天不是对整份课件全文进行完整检索，而是结合当前页、相邻页及按关键词选择的相关页。
5. 点击缩略图星标收藏页面，在问答下方收藏有价值的回答。问答收藏夹支持文本搜索。

示例问题：

- 「用一个生活中的例子解释这一页。」
- 「这里从上一行到下一行，省略了哪一步？」
- 「请区分课件原文和你的补充解释。」
- 「用动画演示卷积核在图像上滑动。」

## 关闭平台连接

在 PowerShell 中设置后再启动：

```powershell
$env:PPT_STUDY_DISABLE_PLATFORM = "1"
.\.venv\Scripts\python.exe -m ppt_study
```

恢复默认行为可在当前 PowerShell 中执行 `Remove-Item Env:PPT_STUDY_DISABLE_PLATFORM` 后重启。运行安装版时，同样可以在设置该变量的终端里启动 `PDReader.exe`。

平台积分是可选远程服务，不包含在开源仓库中。公开源码中的充值配图是占位图。第三方分发者应配置自己的公开端点及联系信息；`src/ppt_study/billing_endpoint.json` 只包含公开服务地址，不应填入密钥。

## 常见问题

**窗口打不开**：检查 WebView2 Runtime 是否安装；从源码运行时确认依赖装入 `.venv`，并从仓库根目录启动。

**PPT 无法打开**：确认 PowerPoint / WPS 可手动打开文件，且对应 COM 自动化组件可用；也可以先导出为 PDF 再试。

**模型看不到截图 / 生成失败**：确认所选模型支持图像输入、Key 有效、URL 是接口根地址，且账户有可用额度。

**公式出现方框或字体错误**：源码分发需要同时保留 `web/vendor/katex/` 下的 CSS、JS 和字体目录。

**视频或动画没播放**：当前是页面图像加部分媒体提取，不等同于 PowerPoint 的完整放映引擎。PDF 附件、媒体编码和外部资源可能不兼容。

**数据在哪里**：默认路径是 `%APPDATA%\PPTStudyCompanion\`。这里包含密钥、缓存和个人数据，请勿提交到仓库。卸载不会自动清除此目录。
