# 数据与联网说明

此文说明本仓库代码当前的行为；它不是模型服务商或平台的隐私政策。

## 本机保存

默认目录为 `%APPDATA%\PPTStudyCompanion\`，包括：

- `settings.json`：API 地址、模型、主题与 **明文 API Key**。
- `cache/`：页面图像、缩略图、提取文本、讲稿和相关缓存；缓存记录可能包含原文件路径。
- 收藏等用户数据，以及可选平台功能的设备标识、地址记录。
- WebView 运行时数据和复制到本机的界面资源。

不要公开此目录。当前版本尚未实现系统凭据库加密保存 API Key。

## 调用模型时发送

生成讲稿会携带当前页图片、文本与相邻页文字。问答还可能携带按关键词选取的相关页文字、近期对话、用户问题和最多三张附加截图。自有 API 请求直接发送到用户配置的服务；平台通道请求发送到配置的平台并由平台调用模型。启用联网搜索时，还依赖所选服务的搜索工具。

课件在本地解析不代表 AI 推理在本机执行。请先确认材料可以交给你选择的服务处理。

## 默认平台连接

客户端启动时会尝试设备登记、查询余额、检查更新，并发送会话与功能使用事件。统计字段包括随机生成并保存在本机的设备标识、时间、功能、耗时、课件文件名、页码或页数、通道及 token 用量等。即使选用自有 API，默认仍会发生这些平台请求；自有 API Key 不作为这些统计事件的字段发送。

本仓库保留的公开平台地址见 `src/ppt_study/billing_endpoint.json` 和 `billing_config.py`。服务端代码与服务端数据保留策略不在本仓库内。

## 禁用平台连接

设置 `PPT_STUDY_DISABLE_PLATFORM=1`、`true` 或 `yes`，再启动程序。客户端的平台地址列表会直接返回空列表，不进行地址发现、平台请求或本地平台服务探测。该选项覆盖登记、统计、余额、平台模型、积分兑换和在线更新。

自有 API 请求依然可用。主动打开的网页、课件外部链接，以及模型服务自身的联网行为不受这个选项控制。

## 反馈问题

Issue 中只附脱敏日志与截图。不要贴出 API Key、支付信息、设备配置或未获授权的课件。若怀疑密钥已公开，请先在相应服务商处撤销该密钥。
